# 月光占卜小屋升级设计

已确认：粉嫩神秘风格；四类场景的离线追问与条件指引；78 张塔罗正逆位；64 卦、卦辞爻辞；可复核抽取；主题动画，可跳过、减少动态。

## 规则

- 塔罗使用安全随机源、无偏整数与 Fisher–Yates 洗牌；单次三牌不放回，正逆位各半。牌阵为现状、阻碍、建议，是本应用使用的三牌阵，不冒称 Waite 原书牌阵。
- 钱币正面 3、背面 2，六掷从初爻向上记录；6/8 阴，7/9 阳；6/9 为动爻，取反得到变卦。
- 原文显示本卦、全部动爻、变卦并读，不套用未经核验的朱熹多动爻取辞表。页面明确说明这是本应用的并读方式。
- 78 张牌的正逆位现代中文释义、64 卦现代提示均为原创整理，和古经原文分别展示。古经文本从公开数字录本导入，记录来源并校核结构。
- 四类场景的建议由结构化回答触发；自由文字用于记录，不宣称理解未解析的文字。移除哈希分数。
- 抽取在触发时确定，动画不改变结果；跨次不排除旧牌旧卦。文案变体使用本机轮换，不影响抽取。
- 不新增云端或 AI 调用；保留历史，支持旧记录回看。

## 验收

64 种阴阳组合和全部 4096 种 6/7/8/9 六爻组合可排卦；三币八种结果分布 1:3:3:1；78 张名称/ID 唯一且有正逆位内容；四场景各分支有根据的建议；抽牌/掷币/实物输入/图鉴/历史均可在手机操作；离线资源齐全；减少动画设置有效。
