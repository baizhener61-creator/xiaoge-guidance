# 小格的心愿指引

一个为 iPhone 优先设计的私人选择指引 PWA。犹豫内容和历史记录都只保存在当前设备的浏览器中；公开构建不包含精确出生资料。

## 本地运行

需要 Node.js 18 或更高版本：

```powershell
npm test
npm start
```

浏览器打开终端显示的本地地址。Service Worker 只在 HTTPS 或 localhost 下启用。

## 安装到 iPhone

1. 将整个目录部署到任意支持 HTTPS 的静态网站服务。
2. 在 iPhone 的 Safari 中打开部署地址。
3. 点击“分享”，选择“添加到主屏幕”。
4. 开启“作为网页 App 打开”，点击“添加”。

此后可从桌面图标进入。第一次成功打开后，核心页面支持离线使用。

## 隐私与边界

- 没有用户账号、服务器数据库或行为分析。
- 最多保留 30 条指引，可在“心愿足迹”中一键清空。
- 结果用于娱乐与自我梳理，不替代医疗、法律、财务或人身安全方面的专业建议。
